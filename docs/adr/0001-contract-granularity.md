# 0001 — 台账以合同为粒度（一行 = 一个合同编号）

日期：2026-09-15　状态：已采纳

## 背景

一个合同常含多个项目（如工民建勘察 + 报告编写 + 化验）。台账按合同还是按项目建行，影响导入去重、金额分摊、财务对账。

## 决策

一行台账 = 一个合同，合同编号为业务唯一标识（导入按其跳过/覆盖/判重）。多项目不拆行，项目名称/工作性质/八大板块取代表值。

## 备选方案

- **项目粒度（一合同多行）**：被否——开票金额、到账金额无法自然分摊到子项目，会立即产生无解的对账问题；且财务对账对象是合同/发票，项目维度会与财务台账打架。

## 后果

- 若未来需要项目维度报表，只能以文本字段（项目名称）做粗粒度统计，无法精确拆金额。
- 合同编号录入质量成为系统数据质量的基石。
