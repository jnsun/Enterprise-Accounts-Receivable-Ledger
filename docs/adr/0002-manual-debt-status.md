# 0002 — 不做系统自动逾期判定，债权状态由人工维护

日期：2026-09-15　状态：已采纳

## 背景

原始需求包含"逾期预警"。v3 实现为债权状态下拉手选（正常/逾期/诉讼/和解）。曾评估改为规则驱动：从挂账时间起算 N 个月未清自动标逾期。

## 决策

不建自动逾期规则。债权状态是**人工维护的催收处置阶段**，其真实用途是区分"正常催收"与"已进入诉讼/和解等处置程序"，而非衡量是否超过合同期限。"逾期预警"需求由人工维护债权状态 + 看板按债权状态筛选汇总来满足。

## 理由

按合同约定付款期限衡量，账上存续项目**几乎全部逾期**——自动判定会产生满屏红灯，毫无区分度，预警形同虚设。

## 后果

- 逾期标签的准确性依赖财务维护纪律；未维护的行默认"正常"，可能低估风险。
- 若未来业务变化（如客户结构转向付款纪律严格的市场），需重新评估自动规则。
