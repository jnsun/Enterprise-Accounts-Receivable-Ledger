# 0003 — 合同额自动带入决算金额，全系统单一结算口径

日期：2026-09-15　状态：已采纳

## 背景

业务惯例：一般项目不专门做决算，直接以合同额替代；仅按工作量结算的项目在完工后单独定案。这决定了"决算金额"的真实语义是**最终结算依据金额**，而非严格的决算审计值。同时所有金额按含税价同口径计算。

## 决策

导入/录入时，决算方式非"按工作量结算"的项目，合同金额**自动带入决算金额**（财务可手动修改）。台账以决算金额为唯一结算金额口径，不双轨存储（不恢复合同金额列参与计算的显示逻辑）。仅工作量结算项目允许决算金额留空，留空时账外应收、应收余额显示"—"且不参与汇总。

## 备选方案

- **手动抄录**：被否——依赖财务纪律，漏录即全院汇总缺一块。
- **合同额参与计算但不落库（虚拟兜底）**：被否——显示值与存储值不一致，长期排查成本高。

## 后果

- 合同额与实际决算出现偏差时，依赖财务手动修正决算金额；修正前看板数字以合同额为准。
- "合同金额"旧字段仅作为导入映射来源，不再作为独立口径展示。
